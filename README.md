- Selected website design and SEO projects
- Historical Google Search Console metrics with reporting periods and role context

- Verified Advanced Python Programming course certificate
- English and Persian SEO resume downloads

## Editing and preview

The site uses static HTML, CSS and JavaScript, with no build step or external libraries.

- `index.html`: English page content
- `app.js`: Persian translations, language switch and chart data
- `styles.css`: responsive layout and styling
- `assets/`: portfolio images, certificate and PDF resumes

Run `python -m http.server 4173` in this directory to preview it locally.

GitHub Pages serves the root of the `main` branch. Persian can be linked directly with `?lang=fa`.

The clinic project's private code and internal operational documentation are not part of this repository. Site copy summarizes portfolio-relevant project experience only.

Portfolio content and supplied project screenshots belong to their respective owners.
